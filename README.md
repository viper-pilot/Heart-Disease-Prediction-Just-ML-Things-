# ❤️ Heart Disease Prediction — Just ML Things

A machine learning project that predicts the likelihood of heart disease using a **K-Nearest Neighbors (KNN)** classification model and an interactive **Streamlit** web application.

## 🚀 Project Overview

This project takes selected patient health parameters as input and uses a trained KNN machine learning model to classify whether the input indicates a likelihood of heart disease.

The project includes:

- Data preprocessing
- Feature scaling using `StandardScaler`
- KNN classification
- Model persistence using `Joblib`
- Interactive Streamlit interface
- Prediction based on user-provided health parameters

## 🧠 Machine Learning Model

The project uses:

**Algorithm:** K-Nearest Neighbors (KNN)

The trained model is stored as:

```text
KNN_heart.pkl
```

The feature scaler used during training is stored as:

```text
scaler.pkl
```

The expected input-column order is stored as:

```text
columns.pkl
```

## 📊 Features Used

The model uses the following features:

| Feature | Description |
|---|---|
| `age` | Age of the individual |
| `sex` | Sex |
| `cp` | Chest pain type |
| `trestbps` | Resting blood pressure |
| `chol` | Serum cholesterol |
| `fbs` | Fasting blood sugar > 120 mg/dl |
| `thalach` | Maximum heart rate achieved |
| `exang` | Exercise-induced angina |
| `oldpeak` | ST depression induced by exercise |
| `slope` | Slope of the peak exercise ST segment |

## 🖥️ Streamlit Application

The project includes a Streamlit web application where users can enter the required values through an interactive interface.

Run the application using:

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/viper-pilot/Heart-Disease-Prediction-Just-ML-Things-.git
```

Navigate into the project:

```bash
cd Heart-Disease-Prediction-Just-ML-Things-
```

### 2. Create a virtual environment

Using `uv`:

```bash
uv venv
```

Activate the environment on Windows:

```powershell
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
uv pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

## 🔄 Prediction Workflow

The application follows this pipeline:

```text
User Input
    ↓
Convert categorical values to numerical values
    ↓
Arrange features in expected column order
    ↓
StandardScaler
    ↓
Trained KNN Model
    ↓
Prediction
    ↓
Heart Disease Result
```

## 📌 Model Persistence

The trained model and preprocessing objects are saved using Joblib so that the application can load them without retraining every time.

```python
model = joblib.load("KNN_heart.pkl")
scaler = joblib.load("scaler.pkl")
expected_col = joblib.load("columns.pkl")
```
